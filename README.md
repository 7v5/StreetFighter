# Streetfighter from Temu

A 2 player fighting game I made in VB.NET with Noah Kohn from 4/30/24 to 5/10/24. Both players play on the same keyboard. It has punching, kicking, jumping, hadoukens, shields, and a hitbox view.

Made in Visual Studio with Windows Forms. Open `StreetFighter.sln` and run it.

Programmers: Elijah Hunter & Noah Kohn

Sprites and the title screen background are from Street Fighter 3 (c) Capcom, used for a class project. The title screen buttons are mine.
